Política de Privacidad

Última actualización: mayo de 2026

Matix es una aplicación de uso personal que ayuda a organizar tareas, proyectos, calendario y apuntes. Esta política explica qué datos maneja la aplicación y cómo.

1. Información que se maneja

  • Datos que tú ingresas: tareas, proyectos, eventos, apuntes y notas que creas dentro de la aplicación.
  • Datos de Google que autorizas: al conectar tu cuenta de Google, la aplicación accede a los eventos de tu Google Calendar para mostrarlos y sincronizarlos. Solo se solicita este acceso si tú lo autorizas.
  • Voz: cuando usas el asistente por voz, el audio se procesa para convertirlo en texto y poder responderte.

2. Cómo se usa la información

Los datos se usan únicamente para ofrecerte las funciones de la aplicación: organizar tu información, recordarte cosas y permitir que el asistente responda. No se venden ni se comparten con fines publicitarios.

3. Servicios de terceros

Para funcionar, la aplicación se apoya en estos servicios, que procesan datos solo para operar Matix:

  • Google — API de Google Calendar, para leer y sincronizar tus eventos.
  • OpenAI — procesamiento de texto y voz del asistente.
  • Supabase — almacenamiento seguro de tus datos.
Uso de datos de Google. El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado. La aplicación accede a tu calendario solo para mostrarte y sincronizar tus eventos, y no usa esos datos para ningún otro fin.

4. Almacenamiento y conservación

Tus datos se guardan en Supabase mientras uses la aplicación. Puedes eliminarlos desde la propia aplicación.

5. Tu control

Puedes desconectar tu cuenta de Google en cualquier momento y revocar el acceso desde la configuración de seguridad de tu cuenta de Google. También puedes borrar los datos que hayas creado.

6. Cambios

Esta política puede actualizarse. La fecha de la última actualización aparece al inicio de la página.

7. Contacto

Para cualquier consulta sobre esta política, escribe a tucorreo@ejemplo.com.
